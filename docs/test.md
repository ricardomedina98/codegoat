# Test Command

`codegoat test` generates unit tests for your code. Auto-detects your test framework, finds untested functions, and generates tests with happy path, edge cases, and error handling.

## Quick Start

```bash
# Generate tests for all files
codegoat test .

# Generate tests for a specific file
codegoat test src/auth.ts

# Generate tests for changed files only
codegoat test --diff main

# Preview without writing
codegoat test . --dry-run

# Force a specific framework
codegoat test . --framework vitest
```

## Framework Detection

Auto-detected from project config files:

| Language | Frameworks detected |
|----------|-------------------|
| JS/TS | Jest, Vitest, Mocha, node:test |
| Python | pytest, unittest |
| Go | Go testing (stdlib) |
| Ruby | RSpec, Minitest |
| Java | JUnit 5 |
| Rust | `#[cfg(test)]` |

Override with `--framework`:

```bash
codegoat test . --framework vitest
codegoat test . --framework pytest
```

## New Files vs Appending

| Scenario | Behavior |
|----------|----------|
| No test file exists | Creates new test file following project convention |
| Test file exists, some functions untested | Appends tests for untested functions only |
| Test file exists, all functions covered | Skips (shows "already fully covered") |

Appended tests are marked with a comment:

```typescript
// === Generated by codegoat ===

describe("register", () => {
  it("should create a new user", () => { ... });
  it("should reject duplicate emails", () => { ... });
  it("should reject weak passwords", () => { ... });
});
```

## Test File Conventions

codegoat follows your project's existing test file location:

| Framework | Source → Test |
|-----------|-------------|
| Jest/Vitest | `src/auth.ts` → `src/auth.test.ts` |
| pytest | `src/auth.py` → `tests/test_auth.py` |
| Go | `pkg/auth.go` → `pkg/auth_test.go` |
| RSpec | `lib/auth.rb` → `spec/auth_spec.rb` |
| JUnit | `src/main/.../Auth.java` → `src/test/.../AuthTest.java` |
| Rust | Inline `#[cfg(test)]` module |

## What Gets Tested

For each exported/public function:
- ✅ Happy path (valid inputs → expected output)
- ✅ Edge cases (empty input, boundary values, null/undefined)
- ✅ Error cases (invalid input, thrown errors)
- ✅ External dependencies are mocked (DB, HTTP, filesystem)

## Flags

| Flag | Description | Default |
|------|-------------|---------|
| `--framework <name>` | Force test framework | auto-detect |
| `--dry-run` | Preview without writing | `false` |
| `--diff [ref]` | Test only changed functions | — |
| `--overwrite` | Replace existing test files | `false` (append) |
| `--out-dir <path>` | Custom test output directory | follows convention |
| `--format json` | Output as JSON | `markdown` |

## With Fix

Generate tests right after fixing issues:

```bash
# Fix issues, then test the fixes
codegoat fix src/auth.ts
codegoat test src/auth.ts
```
